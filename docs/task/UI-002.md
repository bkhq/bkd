## Summary

建立 UI 密度原语，给后续所有 UI 优化 PLAN 提供统一接口。本任务**不改变现有外观**，只新增基础设施 + 在 UI-001 中第一次消费。

- `index.css` 新增 component-density token（icon 3 档、control 4 档）。
- `index.css` 新增 `.chip-surface` component class（消除散落各处的 5-行胶囊样板）。
- 新组件 `<IconButton>`（薄包装 `<Button>`，提供 sm/md/lg + active 状态）。
- 新组件 `<Chip>`（消费 `.chip-surface`，提供 `leading` / `trailing` / `active` props 和 `Chip.Group` 容器）。

## Acceptance

- `apps/frontend/src/index.css` 新增 4 个 `--size-icon-*` + 4 个 `--size-control-*` token。
- `index.css` `@layer components` 新增 `.chip-surface` 和 `data-active='true'` 变体。
- `apps/frontend/src/components/ui/icon-button.tsx` 导出 `IconButton`，props `{ size?: 'sm'|'md'|'lg', variant?: 'ghost'|'subtle'|'primary', active?: boolean }`。
- `apps/frontend/src/components/ui/chip.tsx` 导出 `Chip` 和 `Chip.Group`。
- 任何现有 lint / test 不破。
- UI-001 实施中至少消费一次每个新原语，验证 API 够用。
