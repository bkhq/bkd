## Description

Increase the idle timeout for reusable engine processes so background tasks
that wait for external work are not terminated too early when `turnInFlight`
does not reflect practical idleness accurately.

## ActiveForm

Extending the reusable engine idle timeout to 90 minutes

## Scope

- Update the issue engine idle timeout constant from 10 minutes to 90 minutes.
- Add a focused test assertion that locks the configured timeout value.
- Leave keep-alive and stream-stall behavior unchanged.

## Out of scope

- Changing stall detection thresholds.
- Adding a configurable runtime setting.
