# CI-003 Gate releases on CI

- **status**: in_progress
- **priority**: P1
- **owner**: roy
- **createdAt**: 2026-08-25 16:20

## Description

`release.yml` packages and publishes without running lint, typecheck or tests.
`ci.yml` only triggers on `pull_request` and `workflow_dispatch`, and this
repository pushes straight to `main`, so a tag can be released from a tree that
has never been checked — which is exactly how the Typecheck failure repaired in
[CI-002](CI-002.md) survived several releases.

Acceptance criteria:

- The release workflow runs the full CI suite before it packages anything.
- A failing check stops the release; nothing is published.
- The checks are not duplicated between the two workflows.
- A dry run (`workflow_dispatch` with no tag) exercises the same gate.

## ActiveForm
