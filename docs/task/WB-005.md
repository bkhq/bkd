# WB-005 Remove whiteboard / mindmap feature

- **status**: completed
- **priority**: P1
- **owner**: claude
- **createdAt**: 2026-05-09
- **completedAt**: 2026-05-09

## Description

Remove the project-level whiteboard / mindmap feature in its entirety
(WB-001 through WB-004). The feature is being retired; all routes,
components, schemas, the dedicated DB table, and the related
`issues.is_hidden` field are removed.

Whiteboard-bound issues (created by the AI ask flow) are soft-deleted
in the same migration so they do not surface as visible issues after
`is_hidden` is dropped.

## ActiveForm

Removing whiteboard / mindmap feature

### Migration

- `apps/api/drizzle/0019_drop_whiteboard.sql`:
  1. `UPDATE issues SET is_deleted = 1 WHERE id IN (SELECT bound_issue_id
     FROM whiteboard_nodes WHERE bound_issue_id IS NOT NULL);` — soft
     delete bound whiteboard issues before column drop, so they don't
     leak into the visible list
  2. `DROP TABLE whiteboard_nodes;`
  3. `ALTER TABLE issues DROP COLUMN is_hidden;` — SQLite ≥3.35

### Out of scope

- The `tag` value `whiteboard` on existing soft-deleted issues stays
  as historical data; no further cleanup.
