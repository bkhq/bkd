- **status**: completed

## Description

Follow-up to [DOC-002](DOC-002.md), which moved `bkd.lode.toml` out of the
release assets. `DEPLOYMENT.md` and `migrate-to-lode.ts` are the same kind of
thing — repository files with no version coupling, copied into every release.

- `DEPLOYMENT.md` is a copy of `docs/deployment.md`.
- `migrate-to-lode.ts` is a copy of `scripts/migrate-to-lode.ts`, and it migrates
  a *legacy* launcher layout onto lode, so it is if anything less coupled to the
  release being installed than the config was.

Serving both from the repository leaves the release carrying only what is
genuinely produced by the build: the package and its checksum.

Acceptance criteria:

- The release publishes `bkd-server.tar.gz` and `checksums.txt` only.
- Every reference to the two files points at the repository.
- The `Collect operator files` step disappears rather than lingering empty.

## ActiveForm

Removing the last two doc assets from the release.
