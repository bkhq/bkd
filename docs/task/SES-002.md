# SES-002 Hide managed sessions and add a session detail view

- **status**: completed
- **priority**: P2
- **owner**: roy
- **createdAt**: 2026-08-22 08:05

## Description

Follow-up to [SES-001](SES-001.md). The local sessions list mixes sessions that
are already tracked by BKD with ones that are not, and offers no way to inspect
a session before importing it.

Acceptance criteria:

- The local sessions page lists only sessions that are not already bound to a
  BKD issue.
- Opening a session shows its parsed transcript rendered with the same chat
  components as the issue detail page.
- The detail view reports the session working directory, model, CLI version,
  size and entry count, and states when only the most recent entries are shown.
- The detail view offers the same import action as the list row.
- Focused API and frontend tests pass, followed by repository lint, typecheck
  and build verification.

## ActiveForm

Filtering managed sessions out of the list and adding the session detail view.
