## Description

In Settings -> Models, every model row (detected or custom) gets an edit button that opens a dialog for its details:
display name and extra env vars. Users can add custom models to an engine: an id, a name, the underlying model passed
to the CLI, and env vars (e.g. `CLAUDE_CODE_EFFORT_LEVEL=high`). Executions on a model apply its env vars and pass the
underlying model. Virtual engines are edited from a dialog opened on their card instead of the form at the bottom of
the page.

Acceptance: edit and custom models persist and show up in the model selectors; executing an issue on a custom model
spawns with its underlying model and env vars; overrides on detected models apply their env vars; virtual engines can
be added, edited and removed from dialogs; tests cover config validation, model merge, and execution resolution.
