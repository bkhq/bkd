# ENG-031 Observe Claude subagent activity in issue chat

- **status**: completed
- **priority**: P1
- **owner**: roy
- **createdAt**: 2026-08-22 07:05

## Description

Make subagent work dispatched by `claude-code` (the `Task` / `Agent` tool)
visible in the issue chat instead of collapsing to a single opaque tool call.

Acceptance criteria:

- The claude executor passes `--forward-subagent-text` when the installed CLI
  advertises it, and spawns unchanged when it does not.
- Subagent envelopes (`parent_tool_use_id` set) are normalized with
  `subagent_type` and `task_description` attribution and never appear as
  main-thread messages.
- `task_started`, `task_progress` and `task_notification` are surfaced as
  system entries carrying task id, tool call id, subagent type, last tool name,
  usage and final status/summary.
- The `Agent` tool name renders with the same fidelity as `Task`.
- The issue chat groups subagent entries under their parent tool call,
  collapsed by default, showing live progress and the final summary.
- Per-issue token and cost totals are unchanged.
- Focused API and frontend tests pass, followed by repository lint, typecheck
  and build verification.
