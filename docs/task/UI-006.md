## Description

Five right-side drawers hand-roll the same shell — backdrop, fixed panel,
fullscreen branch, resize handle and header — with gratuitous differences:

- The backdrop is copied five times: two carry `aria-hidden="true"`, two carry a
  meaningless `onKeyDown={undefined}`, one has neither.
- Four drawers use raw `<button className="p-1 rounded …">` for their header
  actions while the session drawer uses the shadcn `Button`, so sizing and hover
  treatment differ.
- Only the session drawer omits minimize, and none of the five closes on Escape.

Acceptance criteria:

- One `SidePanel` renders the backdrop, panel, resize handle and optional header
  for every right-side drawer.
- Header actions use one button component across all drawers.
- Escape closes every drawer; the backdrop is consistently inert to assistive
  technology.
- `FileBrowserContent`, which renders its own header, still supplies the
  standard actions.
- Focused frontend tests pass, followed by repository lint, typecheck and build
  verification.
