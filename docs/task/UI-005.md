# UI-005 Unify duplicated display formatters

- **status**: completed
- **priority**: P2
- **owner**: roy
- **createdAt**: 2026-08-25 10:20

## Description

`lib/format.ts` already exports `formatFileSize`, yet four components declare
their own `formatSize` with three different outputs, so the same byte count
renders as `1.5KB`, `1.5 KB` or `2 KB` depending on the screen. `formatTime` and
`formatDuration` are similarly re-declared.

Acceptance criteria:

- One file-size formatter, used everywhere, with a GB tier.
- The two identical locale date-time helpers collapse into one.
- The two millisecond duration helpers collapse into one.
- The elapsed-since-timestamp helper moves next to the others instead of living
  inside a component.
- Component-local copies are gone.
- Focused frontend tests pass, followed by repository lint, typecheck and build
  verification.

## ActiveForm

Unifying the duplicated display formatters.

## Notes

- The existing shared helper and its test already fix the convention (compact,
  no space: `1.0KB`), so the local variants that added a space are the ones that
  change.
- `LogEntry.formatTime` renders a fixed 24-hour stamp rather than the locale
  default, so it is a different formatter and stays where it is.
- `formatDuration` differs above one minute (`3m` vs `1m30s`); the more precise
  form wins, so the cron page gains seconds.
- 2026-08-25 10:20 — Requested directly by the user; implementation started.
- 2026-08-25 10:50 — Implementation and verification completed.
- `lib/format.ts` now exports `formatFileSize` (with a GB tier), `formatDateTime`,
  `formatDuration` and `formatElapsed`.
- Visible changes: file sizes lose the space before the unit in the file list,
  file viewer and settings dialog; cron durations past a minute gain seconds.
