# UI-007 Upload files from the file browser

- **status**: completed
- **priority**: P2
- **owner**: roy

## Description

The project file browser can list, preview, edit, download and delete files,
but the only way to put a new file into the workspace is to create an issue
attachment or use the terminal. Add a file upload capability so users can
drop or pick local files and write them into the directory currently shown in
the browser.

Acceptance criteria:

- A new authenticated-by-workspace API route accepts multipart uploads into a
  directory under a file-browser root, with the same root and path-traversal
  validation as the existing show/raw/delete/save routes.
- Uploaded file names are restricted to plain basenames; existing files are
  not silently replaced.
- The file browser shows an upload action while viewing a directory and
  accepts drag-and-drop onto the listing; the listing refreshes after upload.
- All new user-facing strings exist in both `en.json` and `zh.json`.
- Focused API and frontend tests pass, followed by the relevant suites, lint
  and typecheck.
