## Description

Review of #145 (`release` -> `main`) found two behavioural defects and three
smaller inconsistencies. Fix them on `release` so the PR can merge.

- Issue list row: actions picked from the right-click menu, and clicks or keys
  inside its rename / delete dialogs, bubbled through the React tree to the
  row. An inactive row navigated to the issue (also right after deleting it),
  and Space / Enter in the rename input were swallowed by the row's
  `onKeyDown`. The row now ignores clicks whose target is outside its DOM
  subtree and keys that were not pressed on the row itself.
- Chat Markdown rendering: `MarkdownContent` always used streamdown's
  `streaming` mode, so a completed message with unmatched markup was rewritten
  (`Use ** as a wildcard` gained a trailing `**`). Completed messages use
  `static`; `streaming` only while `isStreaming`.
- `IssueContextMenuButton` gets a default accessible name
  (`contextMenu.moreActions`).
- Bun 1.4.2 everywhere: CI, the release workflow, `docs/deployment.md` and
  `AGENTS.md` now match `docs/bkd.lode.toml`.
- `AGENTS.md` no longer claims TypeScript 6 is retained for the workspaces.

Acceptance criteria:

- Right-click menu actions and their dialogs never call the row's `onNavigate`;
  Space and Enter reach the rename input.
- A row click and Enter on the focused row still navigate.
- Unmatched markup in a completed message renders as written.
- Frontend suite, lint, typecheck and build pass.
