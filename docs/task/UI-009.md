# UI-009 Move assistant message actions to the footer as copy text / copy Markdown

- **status**: completed
- **priority**: P2
- **owner**: cd
- **createdAt**: 2026-09-09 04:05

## Description

Assistant messages in the chat show two hover actions in the top-right
corner: "View as Markdown" (opens a dialog rendering the message with
react-markdown) and "Copy message". Since UI-008 the chat already renders
Markdown inline, so the view dialog is redundant, and the floating corner
buttons overlap the first line of long messages.

Move the actions into the existing footer row next to the timestamp and
duration, and replace them with two copy actions:

- **Copy text**: the rendered plain text (what the user sees).
- **Copy Markdown**: the raw Markdown source of the message.

Remove the view dialog and its lazy `MarkdownRenderer` import from
`LogEntry`. `MarkdownRenderer` itself stays for the file browser.

Acceptance criteria:

- No top-right overlay buttons on assistant messages; the footer shows
  timestamp, duration and the two copy buttons.
- Copy text writes the rendered text without Markdown markup; copy Markdown
  writes the original content verbatim. Each button shows a transient
  "copied" state.
- i18n keys exist in both `en.json` and `zh.json`; the obsolete
  `viewMessage` / `copyMessage` keys are removed.
- Focused vitest cases pass, followed by the frontend suite, lint and
  typecheck.
