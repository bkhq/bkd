## Description

Register xAI's Grok Build CLI (`grok`) as a third engine type (`grok`) next to
`claude-code` and `codex`, so issues can be assigned to it and run headlessly.

Acceptance:

- `grok` shows up in engine availability with version and auth status, and its models are selectable.
- Execute, follow-up (resume), and cancel work end to end on a real issue.
- Logs render as assistant text, thinking, tool calls (read/edit/command/search), and token/cost usage.
- The Grok normalizer is self-contained: it may mirror the Claude normalizer's approach but must not import from `executors/claude/`.
