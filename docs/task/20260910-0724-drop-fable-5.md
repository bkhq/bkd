## Description

`CLAUDE_MODELS` in `apps/api/src/engines/executors/claude/executor.ts:137` lists both Fable
generations. Keep only 5.1: remove `claude-fable-5` and `claude-fable-5[1m]`.

86f9d78 deliberately kept Fable 5 listed so an issue already pinned to it would keep running
on it. Removing it reverses that: `pickExecutionModel`
(`apps/api/src/engines/model-resolver.ts:12`) keeps a selection only while it exists in the
list, so a pinned issue now falls back to the catalog default (`claude-opus-5`) on its next
execution. The user asked for the removal with that behaviour understood.

Acceptance criteria:

- `GET /api/engines` offers `claude-fable-5-1` and `claude-fable-5-1[1m]`, and neither
  `claude-fable-5` nor `claude-fable-5[1m]`.
- An issue pinned to `claude-fable-5` resolves to `claude-opus-5` instead of failing.
- Opus and Sonnet entries are untouched.
