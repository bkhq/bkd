# ENG-024 Display per-issue token usage totals

- **status**: completed
- **priority**: P1
- **owner**: claude
- **createdAt**: 2026-08-02

## Description

Follow-up to ENG-022: totals now accumulate correctly in
`issues.total_input_tokens/total_output_tokens/total_cost_usd`, but

1. `serializeIssue` (`routes/issues/_shared.ts`) never returns the three
   fields, so the API response omits them despite `Issue` in
   `@bkd/shared` declaring them;
2. the frontend displays token usage nowhere.

## Scope

- Backend: add `totalInputTokens` / `totalOutputTokens` / `totalCostUsd`
  to `serializeIssue` + OpenAPI `Issue` schema; assert in `api-issues`
  test.
- Frontend: `formatTokenCount()` helper in `lib/format.ts` (+ unit test);
  token badge in the issue metadata bar (`IssueDetail.tsx`) showing
  `↑in ↓out · $cost`, tooltip with exact numbers; hidden when all totals
  are zero (pre-fix issues). i18n keys in `en.json` / `zh.json`.

## Out of scope

- Kanban card / issue list row display (visual noise; revisit on request).
- Live SSE push of totals (React Query invalidation on state/done events
  already refreshes the issue).
