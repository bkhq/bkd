## Description

`ci.yml` triggers only on `pull_request` and `workflow_dispatch`, and this
repository pushes straight to `main`, so the pipeline had not run against `main`
in a long time. A manual dispatch after [CI-001](CI-001.md) shows the Typecheck
job failing on two stale tests. Neither runs into the failure at runtime — the
API suite is green — because `bun test` does not typecheck.

- `test/api-issues.test.ts` declares a local `Issue` interface that was never
  extended with the token totals ENG-024 added, while the test asserts them.
- `test/pipeline-context-usage.test.ts` seeds `projects` with a `path` column.
  The column is `directory`; drizzle drops the unknown key, so the row is
  inserted with a null directory and the test passes anyway.

Acceptance criteria:

- `bunx tsc --noEmit -p apps/api/tsconfig.json` reports no errors.
- The API suite still passes.
- A manual CI dispatch on `main` is green.
