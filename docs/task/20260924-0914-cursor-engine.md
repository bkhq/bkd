## Description

Register Cursor's agent CLI (`agent`, formerly `cursor-agent`) as a fourth
engine type (`cursor`) next to `claude-code`, `codex` and `grok`, so issues
can be assigned to it and run headlessly.

Acceptance:

- `cursor` shows up in engine availability with version and auth status, and its models are selectable.
- Execute, follow-up (resume), and cancel work end to end on a real issue.
- Logs render as assistant text, tool calls (read/write/edit/shell/search) with results, and the turn result.
- The Cursor normalizer is self-contained (no imports from other executors).
