# ENG-006 Allow unresolved webhook hostnames on save

- **status**: completed
- **priority**: P1
- **owner**: dev
- **createdAt**: 2026-05-11

## Description

Webhook creation and update currently fail when the target hostname cannot be
resolved from the BKD server environment. This prevents users from saving
temporarily invalid, pending-DNS, or externally configured webhook URLs.

## ActiveForm

Allowing webhook URLs with unresolved hostnames to be saved while preserving
delivery-time SSRF protection.

## Scope

- Add a storage-time webhook URL validation path that does not require DNS
  resolution.
- Use storage-time validation in webhook create/update routes.
- Keep delivery-time DNS/private-IP validation unchanged.
- Add focused tests for unresolved hostname behavior.

## Out of scope

- Changing Telegram webhook behavior.
- Changing webhook delivery retry behavior.
- Adding UI-only validation.
