# ENG-007 Remove claude-code-sdk engine

- **status**: completed
- **priority**: P2
- **owner**: claude
- **createdAt**: 2026-05-15

## Description

Remove the `claude-code-sdk` engine entirely from the codebase. It is the
SDK-backed Claude executor built on `@anthropic-ai/claude-agent-sdk`, running
in-process alongside the legacy hand-rolled stream-json `claude-code`
executor.

Removing it reverses the SDK-migration direction: the legacy `claude-code`
(stream-json) executor is kept as the sole Claude engine; the SDK route is
abandoned. ENG-001 / ENG-002 / PLAN-003 / PLAN-004 are closed as won't-do.

This mirrors ENG-003 (Remove ACP engine): delete the executor module, all
type-union and dispatch references, the SDK-only frontend icon, related
tests, the npm dependency, and documentation mentions.

## ActiveForm

Removing the claude-code-sdk engine and SDK executor from BKD
