# UI-001 ChatInput toolbar density refactor

- **status**: completed

- **completedAt**: 2026-05-11 18:15

## Summary

ChatInput 工具栏一行塞了 12 个互动元素。重排为 3 个分组（高频图标 / 组合配置胶囊 / 主操作），其中：

- Engine + Mode + Model 三个胶囊合并成单一 `EngineConfigChip`（点击展开 popover）。
- Refresh / Files / Clear 三个图标按钮收进新的桌面端 "⋯ 更多" 菜单。
- Diff 徽章从中间右移到 Send 按钮左侧。
- 移动端 `MobileMoreMenu` 顶部加上 "当前引擎" 标识（移动端不显示组合胶囊）。

## Acceptance

- 桌面端工具栏单行高度不变，元素数从 12 降到 ≤8（含 Send/重启）。
- 组合胶囊显示 `<EngineIcon /> {mode} · {model}`，悬停 title 含完整引擎名。
- 组合胶囊 popover 顶部展示当前引擎（不可改），下半部 Mode 切换 + Model 列表。
- 模型列表为空时胶囊退化为 `<EngineIcon /> {mode}`。
- omit-model 锁定时胶囊显示 `· 默认`，popover Model 区禁用并展示 hint。
- 桌面 `⋯` 菜单与 `MobileMoreMenu` 共享同一份菜单项数据源。
- 现有键盘行为（Enter 发送、命令菜单导航、IME 兼容）不变。
- 现有测试通过 + 新增 `ChatInputDensity.test.tsx` 覆盖上述断言。
