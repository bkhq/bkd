# ENG-005 Preserve Codex tool actions for grouping

- **status**: completed
- **priority**: P1
- **owner**: dev
- **createdAt**: 2026-05-11

## Description

Codex tool groups render as one tool message per tool because the app-server
`item/started` tool action entries are marked as streaming. The log pipeline
skips streaming entries for persistence and in-memory replay, leaving only
unpaired `isResult=true` tool result entries for the frontend to render.

## ActiveForm

Preserving Codex tool action entries so frontend tool grouping can pair actions
with results.

## Scope

- Remove streaming metadata from Codex `item/started` tool action entries.
- Keep output delta entries streaming.
- Add focused normalizer assertions for action/result grouping semantics.

## Out of scope

- Refactoring app-server process multiplexing.
- Changing Claude or Claude SDK normalizers.
- Changing frontend grouping behavior.
