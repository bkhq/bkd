# CI-001 Clear the Node 20 deprecation warning in CI

- **status**: completed
- **priority**: P3
- **owner**: roy
- **createdAt**: 2026-08-25 15:30

## Description

Every job in the `check` matrix emits:

```
Node.js 20 is deprecated. The following actions target Node.js 20 but are being
forced to run on Node.js 24: actions/setup-node@v4
```

`actions/setup-node@v4` is the last action in the repository still bundled for
Node 20. The `softprops/action-gh-release@v2` occurrence that produced the same
warning through v0.0.92 is already gone — REL-002 replaced the release step with
the `gh` CLI.

Acceptance criteria:

- No workflow pins an action that targets Node 20.
- The workflows still parse and the pinned Node version is unchanged.

## ActiveForm

Bumping the last Node 20 action in CI.

- **blocked by**: (none)
- **blocks**: (none)

## Notes

- `actions/setup-node` v7.0.0 is the current major (checked against the GitHub
  releases API, published 2026-07-14).
- Signing is untouched: there is no `LODE_SIGNING_KEY` yet, and the workflow
  already degrades to an unsigned upload with a warning, which stays accurate.
- Every job runs through Bun; the Node toolchain may not be needed at all, but
  removing it is a behavioural change and is left alone here.
- 2026-08-25 15:30 — Requested directly by the user; implementation started.

- `grep` finds no remaining action pinned to a Node 20 major across
  `.github/workflows/`.
- The warning itself can only be confirmed gone on the next CI run.
