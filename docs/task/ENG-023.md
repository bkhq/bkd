# ENG-023 Align Codex executor with app-server 0.144.x protocol schema

- **status**: completed
- **priority**: P1
- **owner**: claude
- **createdAt**: 2026-08-02

## Description

Alignment fixes driven by the generated protocol schema
(`codex app-server generate-json-schema --experimental`, codex-cli 0.144.3)
and the openai/codex release notes up to rust-v0.146.0.

Problems found:

1. Auto-approval set in `executors/codex/protocol.ts` lists
   `toolRequestUserInput`, which is not a wire method. The real method is
   `item/tool/requestUserInput` and its response shape is `{answers: {}}`,
   not `{decision}`. Unknown server requests get a `-32601` error reply,
   which can stall/fail a turn.
2. Legacy server requests `execCommandApproval` / `applyPatchApproval` are
   unhandled; their response decision enum is `approved` (ReviewDecision),
   not `accept`.
3. `turn/completed` with `turn.status = failed | interrupted` is normalized
   as a plain success message; `turn.error.{message,codexErrorInfo}` is
   dropped. Standalone `error` notifications are also unhandled.
4. `deprecationNotice` notifications are not logged.
5. `thread/compacted` is deprecated; compaction now arrives as a
   `contextCompaction` thread item (keep legacy handling, add item type).

## Scope

- `executors/codex/protocol.ts` — per-method server-request response map
  (v2 item approvals → `{decision:'accept'}`; legacy exec/patch approvals →
  `{decision:'approved'}`; `item/tool/requestUserInput` → `{answers:{}}`).
  `item/permissions/requestApproval` stays unhandled (response requires a
  full GrantedPermissionProfile; unreachable under
  `sandbox: danger-full-access` + `approvalPolicy: never`) — warn log only.
- `executors/codex/normalizer.ts` — map failed/interrupted turn status
  (error entry with `codexErrorInfo` kind), handle `error` notification,
  handle `contextCompaction` item, keep deprecated paths for back-compat.
- Log `deprecationNotice` (protocol handler).
- Tests in `codex-protocol.test.ts` / `codex-normalize-log.test.ts`.

## Out of scope

- Adopting new capabilities (`turn/steer`, rate-limit panel, thread
  sections) — separate tasks if requested.
- Codex binary upgrade (ops action, recommended 0.144.3 → 0.146.0).
